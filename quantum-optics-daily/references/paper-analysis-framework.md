# 文献深度分析框架

## 模板说明

这是工作流 A 中深度分析环节的详细模板。每篇精读的文献按照这个结构输出。

## 前置要求

**严禁在未获取全文的情况下进行深度分析。** 在开始分析前必须完成：
1. 获取正文全文（arXiv HTML/PDF 或期刊 OA PDF）
2. 检索补充材料（Supplementary Material），如有则获取
3. 检索同行评审文件（Peer Review File），如有则获取
Nature Communications 等 Nature 子刊要求公开 peer review file，应优先获取。

## 输出模板

```
## [篇名]. [英文标题]

### 基本信息
- **标题**：[英文原文标题]
- **作者**：[第一作者 et al. / 具体作者列表]
- **机构**：[第一作者机构 / 通讯作者机构]
- **期刊**：[期刊全名] DOI: [10.xxxx/xxxxx]
- **出版时间**：[YYYY-MM-DD 或 YYYY-MM]
- **开放获取**：[是/否。如果是，给出OA链接]
- **全文来源**：[arXiv ID / 期刊OA PDF链接]
- **补充材料**：[有/无。如有，链接]
- **同行评审文件**：[有/无。如有，链接]

### 文章定位
- **解决什么问题**：[物理问题/技术问题/两者皆有]
  - 如果解决物理问题：具体是什么物理问题？
  - 如果解决技术问题：什么实验技术瓶颈？
- **理论还是实验**：[纯理论/纯实验/理论+实验]
- **做了什么**：[2-3句话概括核心工作]

### 核心贡献（必须给出原文具体段落的依据）
- **相比以前的改进**：
  1. [改进点1]——依据：[原文]
  2. [改进点2]——依据：[原文]
- **获得的指标或突破**：
  - [指标]：数值 A → 数值 B，依据：[原文]
- **解决了什么之前的问题**：
  - [之前的问题] → [本文的方案]，依据：[原文]

### 亮点与缺陷
- **亮点**：[客观评价]
- **缺陷或未解决的问题**：来自原文讨论部分和补充材料的限制说明

### 作者展望
原文 future work 部分的直接引用。

### 审稿人提问
**如果获取到了 Peer Review File**，优先从中提取审稿人的核心问题：
- **审稿人关切**：[审稿人提出的具体问题] → **作者回应**：[作者在 response 中的回应和修改]
- （从 peer review file 中概括 2-3 个最核心的问题和回应）

**如果 Peer Review File 不可获取或审稿人遗漏了重要问题**，可额外补充：
- **额外问题**：[问题] → 回答：[原文依据]

总问题数控制在 3 个。

### 补充材料要点
如果获取到 Supplementary Material，提取其中对正文有关键补充作用的信息：
- [补充材料中的关键数据、额外实验、参数空间等]

### 依据的原文段落
> [关键段落的英文原文]
```

## 注意事项

### 搜索阶段的筛选
1. 从 Semantic Scholar 搜到文章后先看标题和摘要判断相关性
2. 相关的话用 DOI 查 arXiv（如果有）获取全文
3. 如果 paper-lookup 中没有全文，用 exa-search 的 URL extract 获取全文
4. **不要强行分析没有全文、只有摘要的文章**——全文不可获取的论文降级为推荐阅读
5. 检索并获取补充材料和同行评审文件（Nature 系列期刊优先）

### 分析阶段的纪律
1. 核心贡献必须有原文依据——从正文中定位具体段落
2. 指标必须有原文中的具体数值——从正文和图表中提取
3. 缺陷从原文的讨论/结论部分以及补充材料的限制说明中找
4. 审稿人提问优先引用 peer review file；自行提出的问题可以尖锐但不能空穴来风
5. 语言：研究生/博士生能听懂的话
6. 补充材料中对正文有补充的额外数据应纳入分析

### 不要做
- 不要胡诌文章中没有的内容
- 不要把摘要当全文
- 不要替作者脑补实验结果
