# 周报模板

## 输出格式

每次周报输出 Markdown 格式，同时邮件推送：
1. **Markdown** — `reports/[YYYY]/[MM]/[YYYY-MM-DD]-周报.md`（本地存档）
2. **邮件推送** — Markdown 正文发送到 1619838718@qq.com，主题 `量子光学周报 [YYYY-MM-DD]`

SMTP 配置在项目根目录 `.env` 文件中。

## 总体结构

周报长度控制在 2000-4000 字（中文），包含以下部分。

## 标题格式

量子光学精密测量 · 工作进展周报
第 [第几周] 周  [YYYY-MM-DD] — [YYYY-MM-DD]

## 一、本周热点

用 200-300 字概述本周最重要的发现/进展/事件。
结合具体内容，不要用套话。

## 二、科研进展

精选本周读过的最重要的 3-5 篇文章，每篇用 200-400 字写分析摘要。

每篇文章的格式：

### 文章 1：[英文标题]

| 元数据 | 内容 |
|---|---|
| 第一作者/通讯 | [作者] |
| 机构 | [机构] |
| 期刊 | [期刊] DOI: [DOI] |
| 出版日期 | [日期] |

**一句话总结**：[1句话说明这篇文章做了什么]

**核心要点**：
- [要点1]
- [要点2]
- [要点3]

**与你的方向的关系**：这篇文章为什么重要/为什么相关。

**参考文献**：[编号] 作者 et al., 标题, 期刊, DOI: [DOI] [URL]

### 文章 2：[同上]

## 三、企业动态

列出本周值得关注的产业进展。每项 100-200 字。
内容包括：公司新融资/并购/上市、新产品发布、商业化进展、企业合作。

### [编号]. [事件标题]

[简要描述]

**来源**：[URL]

## 四、政策更新

列出本月（或本周）重要的政策动态。每项 100-200 字。
内容包括：政府量子技术战略/资助公告、科研基金项目启动、国际标准/政策文件发布。

### [编号]. [政策标题]

[简要描述，涉及金额、时间、负责机构等关键细节]

**来源**：[URL]

## 五、会议与通知

截止日期临近的会议征稿/注册。

- [会议名称]，[截止日期]，[URL]

## 六、下周预告

简要说明下周预期的重要事件或关注重点。

## 引用格式

全文使用统一的引用格式：
- 科研文章：[1] 作者 et al., 标题, 期刊, DOI: [DOI]
- 企业新闻：[A1] 来源名称, 文章标题, URL
- 政策文件：[B1] 发布机构, 文件名称, URL

超链接保留在 DOCX 文档中。
